Checking local execution capabilities…

A local interface. Your calculation environment.

The workbench reports whether this server supports simulation workers.

Windows and macOS can explore presets and export configurations. Linux and WSL2 can also run the protected simulation queue. Your browser displays the results; calculations run in Python on the server.

01 · CONFIGURE

Define the film

Start from FMR or a confined skyrmion. Set geometry, material and drive in labelled units, with a complete SI configuration to download.

02 · SOLVE

Find the resonances

On Linux or WSL2, relax the magnetization and solve linear eigenmodes and weak-field frequency response using the same Python API.

03 · INSPECT

Keep the evidence

Inspect numerical checks, textures and spectra. Export reproducible results with configuration and file hashes.

Research scope: one uniform layer through thickness, small-signal frequency response and bounded dense problems. Edited configurations need independent convergence checks. Nonlinear comb generation and thickness-dependent modes are outside this workbench.
