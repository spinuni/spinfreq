Downloads and installation

The CI workflow can assemble a release-candidate-review artifact after all prerequisite checks and native platform evidence pass. It contains a wheel, source archive, installation commands and checksummed evidence. See the candidate download and review guide. Hosted success and stable publication remain pending review.

The installed wheel includes the editable example gallery. Run spinfreq-examples --list, then create a project with spinfreq-examples --name localized-source --output my-experiment. Use the printed Python invocation to validate and run it. The first-result tutorial includes exact Windows and Linux/macOS commands; a repository checkout is not needed for these templates.

Current source candidate: 0.1.0rc2, Python 3.11–3.13, MIT license. A stable 0.1.0 release, PyPI package and native application installers have not been published. Source installation is the available distribution route. No GPU or MuMax3 installation is required for the CPU solver.

First time using SpinFreq? Follow Start here. Windows users can use the source ZIP's windows/Install.cmd and Run-Demo.cmd helpers. They create a local Python environment and run the CPU example; no WSL2 is needed. These are source-install helpers, rather than a standalone executable bundle.

Get the source

Download the main-branch source ZIP or clone with Git:

git clone https://github.com/spinuni/spinfreq.git
cd spinfreq
git rev-parse HEAD

The ZIP and branch are moving development snapshots, not immutable release artifacts. Save the revision for reproducibility. Review the changelog and license.

Install the package or application

Create a virtual environment with python -m venv .venv. On Linux/WSL2/macOS use:

.venv/bin/python -m pip install -e '.[web]'
.venv/bin/spinfreq-web

On Windows PowerShell use:

.\.venv\Scripts\python.exe -m pip install -e '.[web]'
.\.venv\Scripts\spinfreq-web.exe

For only the numerical Python package and CLI, omit [web]. Install .[test] for physics tests, or .[test,web,web-test] for HTTP/browser checks. The manual walks through a first simulation.

After installation, spinfreq-doctor --check checks the numerical installation and spinfreq-demo runs a guided CPU example. These local commands work independently of the protected browser queue; Windows browser preview is a separate default mode.

Example inputs

These files use the same schema as the application and can be downloaded without a running simulation worker:

  • prism-fmr.json: fast single-cell susceptibility.
  • periodic-fmr.json: periodic uniform-film FMR.
  • confined-skyrmion.json: coarse 2 nm matched-reference example; refine before quoting continuum frequencies.

Build distributions and an offline website

From a source checkout:

python -m pip install build '.[docs]'
python -m build
python scripts/build_site.py --export results/site

dist/ receives a wheel and source archive. These locally built files are not signed or published release assets. The site export contains the homepage, handbook, assets and example inputs; it can be hosted on a static server or browsed offline. It contains no simulation backend. Its simulator link opens a separately launched local service.

Before publishing: review native Windows evidence, supported-platform checks and scientific scope, then publish immutable artifacts with versioned provenance. See the release plan. Public hosting and release publication remain separate from installing this local application.
