# Provisional SpinFreq identity

![SpinFreq provisional logo](../../spinfreq/web/static/spinfreq-logo.png)

The temporary mark combines a stylized magnetic spin swirl with frequency peaks
and the SpinFreq wordmark. Teal, warm gold and dark navy match the web interface.
It is an illustration of the software's purpose, not a simulated spin texture
or measured spectrum.

The transparent PNG was generated with OpenAI image generation for this project.
The canonical asset is `spinfreq/web/static/spinfreq-logo.png`, reused by the
repository README and web landing page and included in the wheel. It is a raster
image, not an editable vector master. A refined vector identity and small-icon
variants can follow after the first version's interface settles.
